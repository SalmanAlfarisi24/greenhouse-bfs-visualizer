# greenhouse-bfs-visualizer

> Visualisasi interaktif **Breadth-First Search (BFS)** untuk jaringan komponen rumah kaca pintar.

Jelajahi proses BFS, antrean FIFO, dan jalur terpendek menuju buzzer alarm.

## Preview

🚀 **[Live Demo](https://salmanalfarisi24.github.io/greenhouse-bfs-visualizer/)**


## Run locally

Unduh `index.html`, lalu buka di browser. Tanpa instalasi atau dependency.
